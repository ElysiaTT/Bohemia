White space is not a place with nothing in it. It tells us where to pause, which information belongs together and where our eyes should go next.

On a website built around reading, this invisible arrangement often matters more than decoration.

## Establish an order for reading

When every element tries to attract attention, a page loses its center. Design needs to give information different volumes.

A title can be larger, a description quieter, and supporting information further toward the edges. Readers can feel the hierarchy without knowing the rules behind it.

### Size is only part of the story

Two headings with similar font sizes can still have different levels through the space above and below them. Keep related information closer together, and leave more air between separate passages.

Size, weight, color and spacing work best together. No single choice should have to do all the work.

## Give the text a suitable width

Long lines make it easy to lose your place when moving to the next line; very short lines can interrupt the meaning. The width of a text column needs to work with its type size, typeface and content.

Begin with a restrained width and try it with real articles, rather than a few lines of placeholder text.

```css
.reading-column {
  max-width: 46rem;
  margin-inline: auto;
  line-height: 2;
}
```

This is not the only answer. Chinese prose, code samples and tables all need to be put on the page and actually read.

## Less color, more order

One main color, one accent color and a clear range of light and dark can already form a complete visual language.

> Emphasis works because it does not appear everywhere.

An accent color can highlight important links, the current category and a few brand details. When it is used sparingly, readers can understand its meaning more easily.

## Put the design to use

The last step in design is using it. Read a long article on a phone. Switch themes at night. Open the menu with a keyboard. Wait for images on a slow connection.

The real reading experience lives in these particular moments. Look after them, and the page can already be compelling.
